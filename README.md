✈️ Airline Occupancy & Revenue Analysis

Tools: SQL | Python | Power BI
## 📌 Overview
This project investigates booking, revenue, and occupancy data across 8 aircraft types to identify pricing and occupancy optimization opportunities for an airline fleet. The goal was to turn raw booking data into clear, actionable findings for stakeholder decision-making — supported by an interactive Power BI dashboard.

## 🎯 Business Problem
Airlines lose revenue when seats fly empty or when fare pricing doesn't reflect demand. This analysis set out to answer:
- How does occupancy vary across different aircraft types?
- What would be the revenue impact of improving occupancy fleet-wide?
- How do fares compare across Business, Economy, and Comfort classes?

## 🛠️ Tools & Tech Stack
- **SQL** — data extraction and querying
- **Python** — data cleaning and analysis
- **Power BI** — interactive dashboard and stakeholder reporting

## 🔍 Methodology
1. Collected and cleaned booking, revenue, and occupancy data across 8 aircraft types
2. Calculated occupancy rate per aircraft type
3. Modeled the revenue impact of a fleet-wide occupancy increase
4. Compared average fares across fare classes and aircraft types
5. Built an interactive Power BI dashboard to visualize findings for stakeholders

## 📊 Key Findings
- Occupancy rates ranged from **43% to 66%** depending on aircraft type
- A **10% increase in occupancy** across the fleet was modeled to quantify potential revenue uplift
- **Business class fares were consistently priced above Economy** across all aircraft types
